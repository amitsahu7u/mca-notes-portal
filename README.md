MCA Notes Portal - React + Vite
=================================

Run:
  npm install
  npm run dev

Build:
  npm run build

The React frontend includes:
- Semester 1-6 tabs
- Subject cards
- Subject search
- Responsive mobile navigation
- Login modal
- Latest updates and quick links
- Mockup hero image and university seal

Main React file:
  src/main.jsx

Styling:
  src/styles.css
